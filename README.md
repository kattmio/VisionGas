# VisionGas

VisionGas is a sleek, OpenSUSE-first video editor concept inspired by Vegas 13, built for Linux creators and desktop-first production workflows.

This repository contains a polished UI prototype built with React + Vite.

## Features

- Dark cinematic editing workspace inspired by Vegas-style timelines
- OpenSUSE green branding and Linux-ready aesthetic
- Media bin, preview monitor, timeline, and inspector panel
- Export-ready layout for H.264 / 4K workflows
- Fully runnable as a web prototype for local development

## Run locally

```bash
npm install
npm run dev -- --host 0.0.0.0
```

Then open the local URL printed by Vite.

## Build for production

```bash
npm run build
```

## Goals

VisionGas is intended as a conceptual prototype for a Linux-native creative editor that feels fast, flexible, and approachable while respecting OpenSUSE aesthetics and desktop workflows.
